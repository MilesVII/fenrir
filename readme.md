# Fenrir
A sniffer proxy for Janitor AI. Basically a (barely) OpenAI-compatible endpoint that stores incoming requests for a short time

## How to use
* Open a chat with character on Janitor AI
* Add a proxy config:

```
Model Name: anything
Proxy URL: https://fenrir.milesseventh.workers.dev
API Key: anything
```

* Save
* Reload the page
* Reroll a response or just write anything into the chat (you can delete it later)
* Follow the link in the response
